什么是量化交易

量化交易（Quantitative Trading）是用数学模型和计算机程序来识别、执行交易机会的方法。 与主观交易不同，量化策略的每一个决策都有明确的规则，可以被历史数据验证，排除情绪干扰。

🔬

规则驱动

每笔交易都基于预先定义的数学信号，完全可复现

📊

数据驱动

用历史数据检验策略有效性，而非依靠直觉和经验

⚡

自动化执行

程序化下单，消除人工执行的延迟和心理偏差

📐

风险可量化

夏普比率、最大回撤、VaR 等指标精确衡量风险

发展历史

  • 1952
    现代投资组合理论（Markowitz） 均值-方差框架，量化的起点：用数学最优化构建组合
  • 1964–1976
    CAPM 与套利定价理论 Sharpe、Lintner 提出 CAPM；Ross 提出 APT，奠定因子研究基础
  • 1988
    文艺复兴科技（Renaissance）成立 James Simons 用数学和统计方法建立旗舰基金 Medallion，年化超 60%
  • 1993
    动量效应被学术证实 Jegadeesh & Titman 在《Journal of Finance》发表，12-1 月动量显著正收益
  • 1996
    Fama-French 三因子模型 市场、规模、价值三因子，因子投资进入主流
  • 2010s
    机器学习与另类数据 卫星图像、信用卡消费、NLP 情绪分析被纳入量化模型
  • 2020s
    零售量化普及 QuantConnect、Alpaca、AkShare 等平台降低门槛，个人量化成为可能

完整工作流

# 量化策略开发的标准流程

1. 市场假说        # 提出可验证的假设："动量股票未来表现更好"
2. 数据获取        # 历史价格、基本面、另类数据
3. 因子构建        # 将假说转化为可计算的数值信号
4. 回测验证        # 历史模拟，检验 IC、收益率、回撤
5. 样本外测试      # Walk-Forward 防止过拟合
6. 风险分析        # 夏普、Calmar、压力测试
7. 实盘接入        # API 对接券商，模拟盘验证后上实盘
8. 持续监控        # 因子有效性衰减预警，定期再评估

① 动量策略

动量策略基于一个实证发现：过去一段时间表现好的资产，在未来短期内往往继续表现好。 这与有效市场假说相悖，却在全球多个市场、多个时间段被反复验证。

📚 核心论文 Jegadeesh & Titman (1993)：《Returns to Buying Winners and Selling Losers》
用 1965–1989 年美股数据证明，买过去 6–12 个月赢家并持有 3–12 个月，可获显著超额收益。

12-1 月动量因子

跳过最近 1 个月（规避短期反转效应），用 12 个月前到 1 个月前的累计收益作为信号：

Momentum = P(t−1m) / P(t−12m) − 1 
def calc_momentum(closes, as_of, symbol):
    hist = closes[symbol].loc[:as_of].dropna()
    price_now  = hist.iloc[-21]   # 1个月前
    price_12m  = hist.iloc[-252]  # 12个月前
    return price_now / price_12m - 1

波动率调整动量（Barroso & Santa-Clara 2015）

同样涨了 30%，低波动股票的信号质量远高于高波动股票。 用波动率归一化后，策略的夏普比率显著提升，且在动量崩溃期（如 2009 年）损失更小：

Vol-Adjusted Score = Momentum / AnnualVolatility 
annual_vol = hist.iloc[-252:].pct_change().std() * np.sqrt(252)
score = momentum / annual_vol  # 每单位风险的动量强度

质量过滤器

  • 趋势持续性：过去 12 个月中，至少 5 个月上涨（排除单月急拉）
  • 波动率上限：年化波动率 < 80%（排除过于投机的标的）
  • 200MA 过滤：个股价格须站上 200 日均线（顺势而为）

适用场景

维度说明
最优换仓频率月度（周度因摩擦成本过高而损耗显著）
持仓数量10–20 只（过少集中风险大，过多稀释动量效应）
最大风险动量崩溃（Momentum Crash）：市场急反弹时输家大涨
典型超额收益美股年化 3–8%（学术样本），实盘因成本/容量有所摩擦

② 均值回归

与动量相反：偏离历史均值过大的价格，倾向于回归均值。 这在个股的日内 / 短期波动中更为常见，是做市商和高频交易者的主要盈利来源。

布林带策略

上轨 = MA(20) + 2σ　　下轨 = MA(20) − 2σ 
import pandas as pd

ma  = price.rolling(20).mean()
std = price.rolling(20).std()

upper = ma + 2 * std
lower = ma - 2 * std

# 信号：价格触及下轨买入，触及上轨卖出
signal = pd.Series(0, index=price.index)
signal[price < lower] =  1   # 买入
signal[price > upper] = -1   # 卖出

Z-Score 信号

# 用滚动 Z-Score 度量价格偏离程度
z = (price - price.rolling(60).mean()) / price.rolling(60).std()

# |Z| > 2 时认为偏离显著，期待回归
entry_long  = z < -2
entry_short = z >  2
⚠️ 主要风险 均值回归假设价格最终会回归——但在趋势性行情（如 NVDA 2023–2024 的单边上涨）中， 价格持续偏离均值，均值回归策略会持续亏损。建议结合趋势过滤器使用。

③ 多因子选股

多因子模型将若干个经过学术验证的因子加权合成，通过分散化提升单一因子的稳定性。 Fama-French 三因子（1993）和五因子（2015）是最广泛使用的基准框架。

主流因子体系

因子代理变量逻辑经典文献
价值（Value） P/B、P/E、EV/EBITDA 低估值股票被市场忽视，长期存在溢价 Fama & French 1993
动量（Momentum） 12-1月收益率 趋势持续，信息扩散不完全 Jegadeesh & Titman 1993
质量（Quality） ROE、毛利率、Piotroski F-Score 高质量公司长期创造超额价值 Novy-Marx 2013
低波动（Low Vol） 历史日收益率标准差 低风险股票长期回报优于高风险股票（波动率异象） Baker et al. 2011
规模（Size） 市值 小市值公司流动性溢价 Fama & French 1993

合成因子评分

def composite_score(df):
    # 每个因子横截面 Z-Score 标准化，再加权合成
    z = lambda s: (s - s.mean()) / s.std()

    score = (
        0.35 * z(df["momentum_12_1"]) +
        0.25 * z(df["roe"])          +
        0.20 * z(df["gross_margin"])  +
        0.10 * z(-df["pb_ratio"])     +  # 低PB得高分
        0.10 * z(-df["annual_vol"])    # 低波动得高分
    )
    return score.sort_values(ascending=False)

④ 统计套利（配对交易）

统计套利寻找价格走势高度相关的资产对，当二者价差偏离历史均值时开仓， 等价差回归时平仓获利。核心假设：两资产存在协整关系。

协整检验与配对选择

from statsmodels.tsa.stattools import coint
import numpy as np

def find_pairs(prices_df, p_threshold=0.05):
    cols  = prices_df.columns
    pairs = []
    for i in range(len(cols)):
        for j in range(i+1, len(cols)):
            _, p, _ = coint(prices_df[cols[i]],
                              prices_df[cols[j]])
            if p < p_threshold:
                pairs.append((cols[i], cols[j], p))
    return sorted(pairs, key=lambda x: x[2])

# 价差交易信号
spread = log_price_A - hedge_ratio * log_price_B
z      = (spread - spread.mean()) / spread.std()

long_A_short_B  = z < -2   # 价差过低，做多A做空B
short_A_long_B  = z >  2   # 价差过高，做空A做多B
💡 经典配对示例 可口可乐（KO）与百事可乐（PEP）、黄金ETF（GLD）与黄金矿业（GDX）、 同行业银行股之间，往往具有稳定的协整关系。

⑤ 事件驱动策略

通过提前识别和量化企业特定事件（财报、分析师评级变化、并购）对价格的影响， 在事件前后建立方向性仓位。

盈利惊喜（SUE）

SUE = (实际EPS − 分析师预期EPS) / EPS标准差

正向 SUE 往往在财报后数周内持续推动股价上涨（称为 Post-Earnings-Announcement Drift，PEAD）， 原因是机构分析师更新模型、散户追涨存在延迟。

分析师预期修正

# 分析师上调预期 → 未来 1 个月超额收益倾向为正
revision_score = (
    num_upgrades - num_downgrades
) / (num_upgrades + num_downgrades + 1)

# revision_score > 0.3 → 买入信号

止损机制

    if ret <= STOP_LOSS:

# 组合止损：最大回撤超过阈值时转防御仓位

回测方法论

🚨 过拟合是量化研究最大的陷阱 在历史数据上反复调参，几乎可以让任何策略"看起来很好"——但这只是对噪声的记忆，实盘会立即穿帮。

滚动样本外验证（Walk-Forward Test）

# 正确的验证方式：训练集和测试集严格时间隔离
WINDOWS = [
    ("2008-01-01", "2015-12-31", "2016-01-01", "2017-12-31"),

    ("2012-01-01", "2019-12-31", "2020-01-01", "2021-12-31"),
    ("2014-01-01", "2021-12-31", "2022-01-01", "2024-12-31"),
]

常见偏差及规避

偏差类型含义规避方法
前视偏差（Look-ahead）使用了当时未公开的数据所有数据须在再平衡日前已发布
幸存者偏差只用当前存活的股票历史使用历史成分股（点时态数据）
