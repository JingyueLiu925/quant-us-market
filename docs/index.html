先建立一个核心认知

量化交易的本质不是"预测股价"，而是寻找市场里可被系统性利用的定价偏差， 然后在这个偏差消失之前反复交易获利。

🔁 工程类比
把市场想象成一个分布式缓存系统：大多数时候数据是一致的（市场有效）， 但偶尔会出现节点之间的短暂不一致（定价错误）。量化策略就是写一个检测并利用这种 不一致的程序——它们存在的时间窗口有限，发现的人越多，窗口越短。

这意味着：

  • 没有"永远有效"的策略，每种策略都有其适用的市场环境和失效边界
  • 策略越简单参数越少，越不容易过拟合，越可能在样本外持续有效
  • 执行质量（成本、时机、滑点）和信号质量同等重要，有时更重要
  • 真正有效的因子只有少数几个，大多数发表的"新因子"是多重检验的假阳性

市场如何运转（极简版）

股票是什么

购买一只股票，相当于买入一家公司的一小块所有权。 公司盈利时，你按比例分得利润（分红）；公司增长时，这块所有权本身也变得更值钱（股价上涨）。 股价本质上是市场对这家公司未来现金流的折现估计——预期越高，股价越贵。

这里隐含了量化交易最重要的洞察：价格变动 = 预期变动，而不是业绩变动本身。 一家公司利润增长 20%，如果市场已经预期 25%，股价仍然会下跌。 量化策略要捕捉的是"预期的系统性错误"，而非预测绝对业绩。

为什么量化策略能持续赚钱

如果市场完全有效（EMH，有效市场假说），所有信息瞬间反映在价格中，量化策略就不可能持续获利。 但市场并不完全有效——原因是人类的行为偏差是系统性的、可预测的， 而机构套利力量并非无限，有容量和成本的限制。

⚠️ 重要边界：因子拥挤与容量约束 当一个策略被足够多的资金同时使用时，偏差本身会消失——这就是"因子拥挤"（Factor Crowding）。 这就像一个 bug 被所有人同时 patch 了，套利空间关闭。量化策略本质上有容量上限， 超过一定规模后收益衰减，甚至在拥挤解除时引发集中性亏损（2007年8月的"量化危机"是典型案例）。

学术根基

动量效应是金融学文献中记录最充分的市场异象之一，横跨资产类别和地理区域：

研究核心发现数据范围
Jegadeesh & Titman 1993, JF 买入过去 3–12 月赢家、做空输家，持有 3–12 月，月均超额收益 ~1.0% 美股 1965–1989
Carhart 1997, JF 将动量加入 Fama-French 三因子，构成四因子模型（至今是基准） 美股共同基金

两种动量的区别

📊

截面动量（CSMOM）

同一时间点，比较不同股票之间的相对排名。买赢家，做空输家。 捕捉的是"相对信息扩散速度差异"。

📈

时间序列动量（TSMOM）

对同一资产，看其自身过去表现是否为正。过去为正则做多，为负则做空或清仓。 更适合期货和 ETF，散户常用形式。

参数设计：为什么是 J=12, skip=1, K=1

动量策略有三个核心参数：形成期 J（看多少个月的历史）， 跳过期 skip（跳过最近几个月），持有期 K（持有多久）。

  • J=12 个月：学术文献中记录动量效应最显著的窗口。J=6 也有效，J>12 后信号减弱甚至反转（长期均值回归开始主导）。
  • skip=1 个月：Jegadeesh（1990）发现最近 1 个月的收益率存在短期反转——涨太急的股票会在下个月回撤。跳过这 1 个月，可以规避这个噪音。
  • K=1–3 个月：信号的有效期。持有越久，信号稀释越多。月度换仓在信号强度和成本之间取得最好平衡。

动量的行为金融学解释

动量为什么有效，学术界有两种主流解释，至今仍有争论：

🧠

信息反应不足（Underreaction）

投资者对新信息反应太慢（处置效应、锚定偏差）。好消息需要数周甚至数月才能被完全 price in， 价格持续向目标价趋近。Daniel, Hirshleifer & Subrahmanyam, 1998

📉

风险补偿（Risk Story）

动量股在市场崩溃时往往遭受更大损失（2009年）。持有动量组合是在承担某种"隐性风险"， 超额收益是这种风险的补偿。Fama & French, 1996

行业动量：被低估的驱动力

Moskowitz & Grinblatt（1999）JF 的研究发现， 个股动量中 60% 以上来自行业动量——整个行业同步上涨或下跌， 而非个股独立的信息。这意味着：

  • 用行业 ETF 实现动量策略，可以降低成本并分散个股风险
  • 行业轮动（Sector Rotation）是动量策略的简化版本，对散户更实用
  • 选个股时，需要额外区分"行业驱动"和"个股独立信号"

改进：波动率调整动量

Barroso & Santa-Clara（2015）JFE 发现， 动量策略最大的风险是崩溃时的极端亏损，而这些崩溃发生在波动率急剧上升之后。 通过用波动率归一化动量得分，可以在高风险期主动降低敞口：

score_raw = return(t-12, t-1)      ← 原始动量，只看涨幅

score_vol_adj = return(t-12, t-1) / σ_annual      ← 每单位波动获取的动量强度 
# σ_annual 用过去 1 年日收益率的标准差年化得到
daily_returns = closes.pct_change().iloc[-252:]
sigma_annual  = daily_returns.std() * (252 ** 0.5)

score = momentum_12_1 / sigma_annual  # 比 Sharpe 更直观的信号质量度量
🚨 动量策略最大的敌人：动量崩溃（Momentum Crash） Daniel & Moskowitz（2016）JFE 系统研究了动量崩溃现象： 崩溃集中在市场底部反弹初期，此前跌幅最大的股票（动量策略做空标的）反弹最猛， 动量多头组合单月可亏损 30–40%。 2009 年 3 月至 5 月的动量策略净值下跌超过 50%。

根本原因：市场下跌期间，动量策略做多防御性行业、做空高 Beta 股票； 当市场反转时，高 Beta 股票涨幅远大于防御性股票，多空双杀。

规避方法：当大盘指数（SPY）跌破 200 日均线，立即清仓或切换到防御性资产（TLT、GLD）。 这个简单规则可以规避 80% 以上的动量崩溃损失。
✅ 适合用动量策略的情形
  • 大盘在 200 日均线以上（趋势上行期），信号最稳定
  • 月度换仓，不追求日内精度（信号有效期 1–3 个月）
  • 持仓 10–20 只股票，单只不超过总仓位 10%，行业分散
  • 资金规模在 1 亿美元以内（超过后市场冲击开始侵蚀收益）

② 均值回归（Mean Reversion）

实现难度：低–中 适合规模：中小

一句话描述：当价格偏离其历史均衡水平过远时，赌它会回来——偏离越远，回归期望收益越高。

🔁 工程类比
类似控制系统中的 PID 控制器：系统偏离设定点（均值）越远，修正力越强。 价格偏离均值越多个标准差，回归的概率和期望收益越高——但和控制系统一样， 如果"设定点"本身发生了永久性移动（公司基本面真的变差了）， 继续按原来的均值做回归就会持续亏损。

三个时间维度的均值回归

均值回归不是单一策略，不同时间尺度上表现出截然不同的特征：

时间尺度现象核心研究实操频率
短期（1–5天） 上周强势的股票，下周往往弱势；过度单边行情后的反弹 Jegadeesh 1990
Lehmann 1990		 日内或隔夜，需要极低成本
中期（1–12月） ✗ 这个区间反而是动量效应主导，不是均值回归 Jegadeesh & Titman 1993 —
长期（3–5年） 过去 3–5 年输家，未来 3–5 年往往反弹跑赢（长期反转） De Bondt & Thaler 1985 季度换仓，耐心持有
📌 时间尺度悖论 同一只股票，1–12 个月是动量（顺势），3–5 年是均值回归（逆势）。 这不矛盾——短期信息扩散是顺势过程，长期估值修复是逆势过程。 在错误的时间尺度上使用策略，信号会完全反向，直接亏损。

如何验证均值回归是否存在：ADF 检验与 Hurst 指数

在对某个价格序列做均值回归交易之前，应该先统计检验它是否真的均值回归， 而不是随机游走（下跌后继续下跌）。两个常用工具： 

import numpy as np
from statsmodels.tsa.stattools import adfuller

# ── ADF 检验：p < 0.05 意味着序列拒绝"单位根"假设，存在均值回归倾向
result = adfuller(price_series)
p_value = result[1]
print(f"ADF p-value: {p_value:.4f} → {'均值回归' if p_value < 0.05 else '随机游走，谨慎操作'}")

# ── Hurst 指数：H < 0.5 均值回归；H ≈ 0.5 随机游走；H > 0.5 趋势（动量）
def hurst_exponent(ts):
    lags = range(2, 20)
    tau  = [np.std(np.subtract(ts[lag:], ts[:-lag])) for lag in lags]
    return np.polyfit(np.log(lags), np.log(tau), 1)[0]

实际信号构建：Bollinger Band Z-Score

最常用的均值回归信号是对价格序列计算 Z-Score： 相对过去 N 天的均值，当前偏离了几个标准差。

Z = (P_t − μ_N) / σ_N      μ_N = N日均价，σ_N = N日价格标准差

Z < −2 → 超卖信号（做多）     Z > +2 → 超买信号（减仓或做空）
✅ 适合用均值回归的情形
  • 市场整体横盘震荡（大盘指数没有明确趋势方向）
  • 个股因短期非根本性负面事件（季度业绩小幅不及预期）下跌，基本面未变
  • 统计检验已确认该序列具有均值回归特性（H < 0.5 且 ADF p < 0.05）
  • 持有周期 3–14 天，需要较低的交易成本（做市商账户或零佣金平台）
🚨 最危险的情形：趋势行情中强行均值回归（"接飞刀"） 当一只股票从 100 跌到 80，Z-Score 显示 -2.5σ 超卖于是买入， 结果公司基本面已经恶化，股票继续跌到 40——这种情况在真实的基本面恶化中极为常见。

必须配合基本面过滤器：只对 ROE > 10%、债务率正常的公司使用均值回归。 或者设置强制止损：亏损超过 -8% 无条件清仓，不等回归。

③ 多因子选股（Factor Investing）

实现难度：中 适合规模：不限

一句话描述：从多个维度对股票系统性打分，买综合得分最高的一组，通过分散持仓和低换手率获取稳定超额收益。

🔁 工程类比
完全类似机器学习里的特征工程 + 线性集成： 每个因子是一个特征（动量、ROE、P/B、波动率）， 横截面标准化等价于特征归一化（Min-Max 或 Z-Score）， 加权合成等价于一个线性模型对多个特征打分。 差别在于这里的"标签"是下个月的相对收益， "训练集"是金融学论文中几十年的历史数据， 而不是你自己跑出来的——用别人跑出来的结果是有意义的， 因为这些因子背后有行为金融学和经济学的理论支撑，而不只是数据拟合。

如何衡量因子的预测能力：IC 与 ICIR

选择因子时不能只看回测收益——收益可能来自特定时期的偶然因素。 更健壮的指标是IC（信息系数）和ICIR（IC 信息比率）：

IC_t = Spearman_rank_corr(factor_values_t,   future_returns_{t+1})

ICIR = mean(IC) / std(IC)      ← 越高越好，> 0.5 被视为稳定信号

IC 衡量某期因子排名与下期收益排名的相关性（Spearman），取值 -1 到 1。 一个好因子的 IC 通常只有 0.03–0.08——听起来很低， 但在 500 只股票的截面上，持续为正的 IC 每个月可以积累出显著的超额收益。 ICIR 衡量的是这个信号的稳定性，一个 IC 均值为 0.05 但 ICIR 为 1.0 的因子， 远比 IC 均值 0.08 但 ICIR 为 0.3 的因子实用。

因子组合的关键原则

  • 低相关性优先：选择相互相关性低的因子（如动量 + 低波动，两者在市场崩溃期负相关），组合效果远好于选多个同类因子
  • 等权优于优化权重：对历史数据过拟合的权重在样本外几乎必然表现更差。简单等权在大多数情况下稳健性更好
  • 横截面排名标准化：对每个因子在同一截面内做 percentile rank（0–1），消除量纲差异，再加权合成

因子动物园问题（Factor Zoo）

⚠️ 学术界的警告：316+ 因子，大多数是假的 Harvey, Liu & Zhu（2016）RFS 统计了学术期刊中发表的 316 个"有效因子"， 认为其中大多数是多重检验的假阳性——在 316 次实验中， 即使随机数据也会出现大量"显著"结果。

他们建议，新因子的 t-统计量门槛应从传统的 2.0 提升到 3.0， 才能可信地宣称发现了新因子。对于非学术研究者，建议只使用有明确经济学解释的少数因子， 而不是追逐新发表的"因子"。
✅ 多因子选股最适合的场景
  • 持仓周期 1–6 个月，换手率低，交易成本可控
  • 资金体量适中或较大（需要持仓分散到 20–50 只股票）
  • 希望收益来源可解释、可归因，而非黑盒模型
  • 追求稳定的风险调整收益，而非最大化短期绝对收益

④ 统计套利（Statistical Arbitrage）

实现难度：高 适合规模：中大

一句话描述：找两只走势高度相关（协整）的资产，当价差偏离时做多被低估方、做空被高估方，等价差收敛时获利。

🔁 工程类比
类似分布式系统中的数据一致性检测与修复：两个副本（两只股票） 理论上应该保持同步（协整关系），当检测到不一致（价差偏离正常区间）时触发交易（修复）， 等一致性恢复（价差回归）后平仓获利。 关键在于：你需要先证明"两个副本本来就应该同步"（协整检验）， 否则它们只是碰巧走了一段相似的路，随时可能永久分叉。

协整（Cointegration）：比相关系数更强的条件

两只股票价格高度相关，不等于它们适合做配对交易。 以下例子说明为什么：2010–2018 年，美国债券价格和美股均呈上涨趋势，相关系数为正， 但这只是"伪相关"——它们各自由不同的宏观因素驱动，并没有均值回归的约束关系。

协整是更严格的条件：两个价格序列本身可以各自随机游走， 但它们的线性组合（价差）是平稳的（具有均值回归特性）。 这意味着价差偏离后，存在经济力量将其拉回——通常是来自共同的基本面驱动因素。 

from statsmodels.tsa.stattools import coint, adfuller
import numpy as np

# Step 1: Engle-Granger 协整检验
score, pvalue, _ = coint(price_A, price_B)
if pvalue < 0.05:
    print("协整关系显著，可以做配对交易")

# Step 2: 用 OLS 估计对冲比例（hedge ratio）
import statsmodels.api as sm
model  = sm.OLS(price_A, sm.add_constant(price_B)).fit()
beta   = model.params[1]   # 每买 1 单位 A，做空 beta 单位 B
spread = price_A - beta * price_B

# Step 3: 估计价差回归的半衰期（half-life），决定持仓时间预期
delta     = spread.diff().dropna()
lag       = spread.shift(1).dropna()
lm        = sm.OLS(delta, sm.add_constant(lag)).fit()
half_life = -np.log(2) / lm.params[1]
print(f"价差均值回归半衰期：{half_life:.1f} 天")
# 半衰期 5–30 天：适合交易；> 60 天：信号太慢，成本太高

⑤ 事件驱动策略（Event-Driven）

实现难度：中 适合规模：中小

一句话描述：在可预期的企业事件（财报、收购、评级调整）前后建仓，利用市场对新信息的系统性反应不足。

最核心的子策略：盈利惊喜后的漂移（PEAD）

Ball & Brown（1968）JAR 最早发现， 财报超出分析师预期后，股价会在接下来数周内持续跑赢大盘， 而不是在财报日一次性完成价格调整。 这个现象被称为 PEAD（Post-Earnings-Announcement Drift，财报发布后漂移）， 是学术文献中最稳健的市场异象之一，在几乎所有地区和年代都有记录。

~5–8%
最高 SUE 分位股票，财报后 60 天超额收益（Bernard & Thomas 1989）
60天
信号的有效窗口，60天后漂移基本消散
40年+
现象的持续时间（1968年至今仍有记录）

量化盈利惊喜：SUE 指标

不能只看"超没超预期"，要量化惊喜的幅度与历史稳定性的比值—— 这就是 SUE（Standardized Unexpected Earnings，标准化意外盈利）：

SUE = (EPS_actual − EPS_expected) / σ(EPS_surprise_历史)

分子 = 实际 EPS - 分析师共识预期；分母 = 过去若干季度的惊喜幅度标准差

这个标准化很关键：同样超预期 10 美分，对一个每季度预期稳定的公司（σ 小，SUE 大） 信号更强，对一个业绩极不稳定的公司（σ 大，SUE 小）信号更弱。

为什么 PEAD 还能持续存在

如果这个异象已经被发现超过 50 年，为什么还没被套利掉？学术界的解释：

  • 短卖约束：PEAD 的负向部分（超低 SUE 股票的下跌漂移）被短卖限制阻止了完全套利，尤其是小盘股
  • 机构调仓摩擦：大型基金调仓有流程审批、窗口期等限制，无法在财报日后立即全仓调整
  • 风险：策略虽然有正期望收益，但单个事件的结果方差很大，机构难以承受短期亏损

回测的本质：为什么聪明的人也会被骗

回测（Backtest）是用历史数据模拟策略的表现。它的根本问题和所有历史拟合方法相同： 在历史数据上表现完美，不代表未来会有效。 但量化交易的回测有几个远比软件测试更隐蔽的陷阱， 即使经验丰富的工程师也容易忽略。

🧪

样本内回测（In-sample）

等价于单元测试——只能证明代码逻辑正确，不能证明策略有效。 在同一段数据上开发策略并回测，即便随机策略也能被调参到"很好看"。

🚀

样本外测试（Out-of-sample）

等价于 A/B 测试——用完全没见过的时间段验证。 但注意：即使是样本外测试，如果你反复调整策略直到样本外也好看， 样本外就变成了"第二个训练集"，失去了检验意义。

八大回测陷阱

1
前视偏差（Look-ahead Bias）
最常见、最致命的错误；会让任何策略看起来"完美"

前视偏差是指在回测中使用了决策时刻在现实中尚未公开的数据。 它不会报错，代码看起来完全正确，只是逻辑上穿越了时间。

典型案例

  • 财务数据滞后：公司 12 月 31 日的年报，实际要到次年 3–4 月才发布（SEC 要求 90 天内）。 如果在 1 月 15 日的回测中使用"去年年报的 ROE"，就用了未来数据—— 现实中 1 月 15 日你根本不知道这个数字。
  • 指数成分股：用当前的 S&P 500 成分股做 2005 年的回测—— 但 2005 年这些公司中有很多还不在指数里（它们是因为后来业绩好才被纳入的）。 等于你在 2005 年就"知道"了哪些公司未来会成功。
  • 分析师共识：分析师的盈利预期在每个交易日都在变化。 如果数据库存储的是"最新"预期而非"当时"的预期，回测就存在前视偏差。

量化影响

前视偏差对回测结果的影响幅度没有上限——一个纯靠前视偏差的"策略"， 可以展示出年化 50%+ 的"收益"，却在实盘中接近零甚至为负。

如何避免

  • 对所有基本面数据，存储实际发布日期（Filing Date），而非报告期结束日期
  • 在回测逻辑中，每个决策时间点只允许使用"在该时间点之前已发布"的数据——这叫 Point-in-Time（PIT）数据
  • 使用提供 PIT 数据的数据商（如 Compustat 的 Point-in-Time 版本，SimFin 的历史快照）
2
幸存者偏差（Survivorship Bias）
只用"活下来"的股票回测，等于只统计了命运好的那一半

如果你用今天的 S&P 500 成分股做 2000–2010 年的历史回测， 你的股票池里不包含那些在这期间破产、退市、被收购的公司—— 而这些公司在 2000 年其实还在指数里。 你的回测相当于在 2000 年就知道了哪 500 家公司能活过 10 年。

量化影响

Elton, Gruber & Blake（1996）JF 对美国共同基金的研究发现， 幸存者偏差会使历史收益虚增约 1.4%/年。 Brown et al.（1992）估计对某些股票策略的影响高达 3%/年。 听起来不多，但 20 年复利后，这意味着终值误差超过 50%。

更严重的问题：退市股票在退市前的最后几个月往往有极端负收益（−50% 至 −90%）， 这些极端亏损在不含退市股票的数据集中完全消失了。

如何避免

  • 使用包含历史成分股快照的数据库，记录每只股票在每个时点是否属于你的股票池
  • 在股票从股票池退出时（退市、被并购），使用其退市时的实际收益（包括退市前的亏损），而非直接删除
  • 如果使用付费数据，确认其是否包含"已退市股票"的历史数据
3
多重检验与数据挖掘（Multiple Testing / p-Hacking）
在同一数据集上尝试 100 种策略，5 种会"显著有效"——纯粹靠运气

假设你系统性地测试了 100 种不同的参数组合（不同的动量窗口、不同的因子权重、 不同的止损线），其中 5 种在 5% 显著性水平下"通过了检验"。 这 5 种真的有效吗？不一定——在 100 次随机实验中，本来就期望有 5 次假阳性。

学术界的警告

Harvey, Liu & Zhu（2016）RFS 系统回顾了 1967–2016 年间 发表的 316 个"显著因子"，认为绝大多数是多重检验的产物。他们提议：

  • 传统显著性门槛 t > 2.0（p < 0.05）已经不够——面对大量检验，应提高到 t > 3.0（p < 0.003）
  • 发表偏误（Publication Bias）：只有"有效"的策略才会被发表，期刊上看到的结果已经经过自然筛选，是从更大量失败实验中存活下来的

Deflated Sharpe Ratio：考虑试验次数后的真实显著性

Bailey & López de Prado（2014）JPM 提出了修正后的 Sharpe 比率检验方法：当你进行了 N 次参数搜索后， 单次结果的"显著夏普比率"门槛需要随 N 上升：

SR_min ≈ (1/√T) × Φ⁻¹(1 − α/N)      T=样本数，α=置信水平，N=试验次数

直觉：你跑了 100 次实验，即使策略完全无效，最好的那次结果的 Sharpe 也有 ~0.8。因此观察到 Sharpe = 1.0 时，你应该非常怀疑它是否真的显著，而不是立刻宣告"找到了好策略"。

如何避免

  • 在开始任何参数搜索之前，先写下你的假设和预期的参数范围，而不是事后解释你找到的结果
  • 严格区分"探索阶段"（在训练集上可以随便试）和"验证阶段"（验证集只能用一次）
  • 优先使用有明确经济学解释的参数值（如 J=12 个月，有文献依据），而非网格搜索出来的"最优"值
  • 对最终策略，报告 Deflated Sharpe Ratio，注明搜索了多少种参数组合
4
过度拟合与样本外失效（Overfitting）
参数越多、历史越短，过拟合风险越高；样本内漂亮，样本外归零

过拟合是"用历史数据优化参数"的必然代价：参数越多，模型越能拟合历史噪音， 样本外性能就越差。量化策略中，即使只有 3–4 个参数，过拟合也很容易发生。

为什么时间序列数据比截面数据更容易过拟合

20 年月度数据 = 240 个观测值。这听起来不少，但金融收益率的信噪比极低—— 噪音（市场随机性）远大于信号。如果你的策略有 5 个参数， 等效自由度 240 − 5 = 235，看似充足， 但当你测试了 100 种参数组合之后，有效自由度其实大幅缩水。

更隐蔽的过拟合：即使只有 1 个参数（如动量形成期）， 如果你测试了 J = 1, 2, 3, ..., 24 个月并选择效果最好的， 这 24 次搜索本身就构成了多重检验意义上的过拟合。

如何避免

  • 奥卡姆剃刀原则：能用 2 个参数解决的问题，不用 5 个参数。简单模型在样本外更稳健。
  • Walk-Forward 验证：见下一节的详细说明
  • 参数稳定性检验：最优参数附近的参数也应该表现类似。如果 J=12 远优于 J=11 和 J=13，说明是噪音
  • 使用文献中的参数：学术文献中经过多个独立数据集验证的参数（如 J=12）比你自己优化出的参数更可信
5
交易成本低估（Transaction Cost Underestimation）
回测中最容易被忽略，实盘中最大的"隐性税"

很多回测假设可以按收盘价无成本交易，或只考虑佣金。 但真实交易的成本来源远不止佣金，尤其是策略换手率较高时， 总摩擦成本可能是佣金的 5–10 倍。

成本的四个来源

换手率的复利效应

假设每次换仓的双边摩擦成本为 0.12%（美股），换手率 30%：

  • 周度换仓：52 次 × 30% × 0.12% ≈ 每年消耗 1.87%
  • 月度换仓：12 次 × 30% × 0.12% ≈ 每年消耗 0.43%

这 1.44% 的年化差距，在 20 年复利后意味着终值相差约 33%。 这就是为什么对于动量这类信号衰减慢的策略，月度换仓往往优于周度换仓—— 不是信号质量的差距，而纯粹是成本节省。

如何在回测中正确估计成本

# 每次交易时，扣除双边滑点 + 佣金的估算
COST_PER_TRADE = 0.0006  # 美股：约 0.06% 双边（含点差）
COST_PER_TRADE = 0.002   # A股：约 0.2% 双边（含印花税 0.1% + 佣金 0.05%×2 + 点差）

# 换仓时，对每笔买入和卖出分别扣除成本
trade_value = abs(new_weight - old_weight) * portfolio_value
cost        = trade_value * COST_PER_TRADE
portfolio_value -= cost
6
流动性假设（Liquidity Illusion）
回测假设可以按收盘价买入任意数量，现实中这个假设经常不成立

回测通常假设在再平衡日收盘时，可以按收盘价买入或卖出任意数量的股票—— 这在理论上隐含了无限流动性。现实中有两个硬约束：

约束一：容量限制

如果你的策略买入某只小盘股，买入金额不应超过该股票当日交易量的 1–5%—— 否则你的订单本身就会推高价格（市场冲击），让你用更贵的价格买入。 实证研究（Almgren & Chriss 2001 JRI）表明， 市场冲击成本大约与订单规模的平方根成正比：

Impact ≈ σ × √(Q / V)      σ=股票波动率，Q=你的订单量，V=当日日均成交量

这意味着：一个在 1000 万美元规模时夏普比率 1.5 的策略， 在 1 亿美元规模时夏普比率可能只有 0.8，10 亿美元时可能为负。

约束二：执行价格假设

回测按收盘价成交，但实际中：

  • 收盘价是最后一笔成交价，实际大订单会影响收盘价，出现"自我实现"的价格
  • 如果策略在收盘前才确定持仓，实际执行往往是次日开盘，会有过夜缺口风险
  • 实施缺口（Implementation Shortfall）：论文收益 vs 实际收益的差距， 通常在 0.1–0.5%/次

如何估计策略的容量上限

# 粗略估计：对于持仓中每只股票，计算你的仓位是否在流动性约束内
for symbol in portfolio:
    position_value  = portfolio[symbol] * price[symbol]
    daily_volume   = avg_daily_volume[symbol] * price[symbol]
    participation  = position_value / daily_volume
    if participation > 0.05:  # 超过 5% 日成交量，市场冲击不可忽视
        print(f"⚠ {symbol}: 流动性不足，回测结果可能虚高")

时间段选择偏差（Data Snooping Bias）
选择"效果最好"的回测时间段，等于再次过拟合

假设你测试了 2000–2023 年、2005–2023 年、2010–2023 年三个时间段， 选择其中表现最好的作为"回测结果"展示—— 这和参数优化一样，是对时间段的过拟合。

不同时代的市场特征差异很大

时间段市场特征对动量策略的影响
1980–2000 大盘长牛，利率持续下行，信息技术落后 动量效应极强（机构信息优势大）
2000–2008 两次大熊市（互联网泡沫+金融危机），高波动 动量在崩溃时遭受重创
2010–2020 QE 驱动的长牛，低波动，科技股主导 动量策略出现科技股偏向
2020 至今 COVID 冲击、通胀、利率急升、AI 浪潮 传统因子相关性被打乱，需要重新校准

如何避免

  • 使用全部可用历史数据，包括你不喜欢的时间段（2000–2002 互联网泡沫、2008–2009 金融危机）
  • 明确报告策略在不同市场环境（牛市、熊市、横盘）下的表现，而不只是整体年化收益
  • 特别测试"大回撤时期"的策略行为——好的策略应该有明确的失效原因，而不是不可解释地亏损
8
制度变迁与结构性断裂（Regime Change）
策略在历史上有效，不代表当前的市场结构中仍然有效

金融市场不是物理系统，它会对被发现的规律做出反应。 当一个策略被足够多的资金采用，或者市场结构发生根本性变化时， 历史上有效的策略可能完全失效。

重要的结构性变化时间点

  • 2000 年 Reg FD（公平披露规定）：美国 SEC 规定，公司不得对特定分析师选择性披露信息—— 减少了机构的信息优势，削弱了基于内部消息的短期动量。
  • 2007–2008 年 HFT 兴起：高频交易主导了市场微观结构， 买卖价差大幅收窄，但也使短期均值回归策略的利润空间显著压缩。
  • 2010 年后被动投资的崛起：指数基金规模超过主动管理基金—— 大量资金按市值权重买入，使得市值因子（规模因子）的套利空间减少。
  • 2020–2022 年零利率到高利率转变： 折现率的急剧上升让估值逻辑发生结构性变化，过去低利率期间有效的成长股动量策略大幅回撤。

如何识别制度变迁

没有完美的方法，但以下信号值得警惕：

  • 因子的 IC 均值在近 2–3 年显著低于历史平均（信号衰减）
  • 策略的因子暴露（Factor Loading）随时间漂移，与设计初衷不符
  • 同类策略的多个独立实现都同时出现持续亏损（因子拥挤解除）
  • 市场的相关性结构发生根本性变化（如 2020 年 3 月，几乎所有资产同时崩溃）
📌 保持策略简单性的另一个理由 越简单的策略，其有效的经济学机制越清晰，你越容易判断这个机制是否仍然成立。 "买入过去一年的赢家"背后的机制（信息扩散延迟）不会因为市场结构变化而完全消失； 而一个依赖 50 个参数精确校准的复杂模型， 在市场结构稍有变化后就可能因为其中某个参数的失效而整体崩溃。

Walk-Forward 验证：时间序列数据的正确交叉验证

传统机器学习中的 k-fold 交叉验证不适用于时间序列数据—— 因为随机分割会导致用"未来数据训练、过去数据验证"的时间泄露。 正确的方法是 Walk-Forward（滚动窗口）验证： 

# Walk-Forward 验证框架
# 每轮：在训练窗口内确定参数 → 在完全独立的测试窗口上评估 → 滚动

  { "train": ("2007", "2014"),  "test": ("2015", "2016") },
  { "train": ("2009", "2016"),  "test": ("2017", "2018") },
  { "train": ("2011", "2018"),  "test": ("2019", "2020") },
  { "train": ("2013", "2020"),  "test": ("2021", "2022") },

# 只有在所有测试窗口上都稳定正收益，策略才值得进入实盘验证

Walk-Forward 的关键设计选择

设计维度选择考量
训练窗口长度 至少包含一个完整牛熊周期（5–8 年） 太短：参数估计不稳定；太长：制度变迁导致早期数据失效
滚动 vs 扩展 扩展窗口（越来越多数据）更稳健 滚动窗口（固定长度）可以捕捉制度变迁，但参数会随时间变化
测试窗口长度 1–2 年 太短：结果随机性大；太长：策略跨越多个市场环境，平均了重要差异
参数是否允许更新 保守做法：固定参数，只更新信号数据 允许参数更新会引入额外的过拟合风险
💡 Walk-Forward 结果的解读标准 一个策略要被认为"通过了验证"，应满足以下全部条件：
① 所有测试窗口的平均年化超额收益 > 0（包含 2008、2020 这样的困难时期）
② 夏普比率在多数测试窗口 > 0.5（不要求每个窗口都 > 1.0，但不能有大量严重亏损的窗口）
③ 样本外收益与样本内收益的比值（OOS/IS Ratio）> 50%（过拟合会导致这个比值很低）
④ 策略有清晰的经济学或行为金融学解释，知道它在什么市场环境下会失效

风险控制：系统容错设计

量化系统的风控逻辑与分布式系统的容错设计完全一致： 不是防止单次错误，而是限制单次错误的影响范围，并保证整个系统在局部故障下仍能生存。

🔌

单股止损（Circuit Breaker）

单只股票亏损超过 −15%，立即无条件清仓。等价于单个服务实例超时后的熔断—— 不等恢复，直接隔离。

🛡️

组合熔断（Drawdown Guard）

整个组合从高点回撤超过 −20%，全部清仓切换到防御资产（TLT、GLD）。 等价于系统降级——核心服务保住资本，等待环境改善。

📊

分散持仓（Load Balancing）

单只股票不超过总仓位 10%，行业集中度不超过 30%。 等价于负载均衡——防止单点故障影响整体。

🌊

大盘过滤（Overload Protection）

当市场指数跌破 200 日均线，暂停进攻性操作。等价于限流—— 在系统过载时拒绝新请求，保护现有资源。

交易成本：最大的隐性杀手

大多数人低估了交易成本的长期影响。 一个年化收益 15% 的策略，如果年化摩擦成本是 5%，实际净收益只有 10%—— 降幅 33%，而且这个差距会随着时间复利放大。

💡 工程师视角的核心建议 不要从"哪个策略回测收益最高"出发——那是在优化历史噪音。 应该从"这个策略的经济学假设在什么条件下会失效"出发。 理解失效条件，才能设计正确的熔断和监控机制， 才能在策略开始失效时识别出来（而不是茫然地持续亏损等待"回归"）。 这和系统设计中先想清楚故障模式再做容灾，是完全一样的思路。
